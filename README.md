# alfresco-api

Alfresco API ที่ใช้ logic และ response ตาม UserAlfresco-api โดยใช้บัญชีกลางจาก .env

ตั้งค่า ALFRESCO_HOST, ALFRESCO_USER, ALFRESCO_PASS, API_TOKEN, WRITE_API_TOKEN และ PORT (ค่าเริ่มต้น 3005) แล้วรัน npm install และ npm start

ดู endpoint, request และ response ปัจจุบันใน [API_SPEC.md](API_SPEC.md) ทุก API legacy และ /dev-api ถูกยกเลิกแล้ว

รันทดสอบด้วย npm test
